\subsection*{One response representation, different endpoint behaviors}

The matched test establishes a response benefit for one endpoint, not for every
possible predictor. To test whether the representation remains useful across
learners, we combine the same 15 frozen response predictions with different
molecular representations and endpoint models. We evaluated ExtraTrees, residual multilayer
perceptrons (MLPs), separate structure and response branches, a linear predictor
with a neural residual, message-passing graphs with size-sensitive readouts, frozen
MoLFormer representations with neural heads, TabM parameter-sharing ensembles,
and TabPFN-3.5 in-context prediction (Table~\ref{tab:endpoints}). TabM shares
most weights across multiple neural predictions; TabPFN uses a pretrained
transformer conditioned on labelled training rows.\cite{tabm2025,tabpfn2025,tabpfn35}
A MoLFormer--ExtraTrees fit changes the representation while retaining a tree
endpoint. Supplementary Figs.~8--10 depict the mechanisms. We ask separately
which endpoints predict most accurately and whether adding the responses helps
each one; these need not have the same answer.

This architecture comparison is retrospective: the evaluation sets were already
known during method development. Within each outer partition, configuration and
training duration were chosen using only training-side validation data. We
completed longer-training, representation and width challenges, locked the
selection policy, and then fitted the final models. The policy selected TabPFN
in all five ARROW folds and the external fit. Input recipes can differ by
partition; the external TabPFN fit uses RDKit descriptors, a frozen MoLFormer
encoding and the responses. No-response controls inherit each selected recipe;
they are paired ablations, not separately optimized structural baselines.
The common comparison for all nine fixed configurations uses the same ARROW-85,
External-220 and nested
Strict-97 evaluation identities, with a paired no-response fit for each
configuration. Eight configurations were also refitted for the separate
size-held-out diagnostic; the MoLFormer--ExtraTrees combination was not.
Shuffled-response and chemical-separation results below concern the ExtraTrees
fits and are not claims about the other endpoints.

The lowest full-model point estimate changes with the evaluation: TabPFN has
0.199 kcal mol$^{-1}$ on ARROW-85, a MoLFormer neural head has 1.111 on
External-220, ridge plus a neural residual has 1.429 on Strict-97, and TabPFN
has 1.318 in the exploratory size refit (Table~\ref{tab:endpoints}). ExtraTrees
also fits the small reference set closely at 0.202 but is less accurate on the
size holdout. These ranks are descriptive, not a statistically established
ordering of all endpoint pairs.

Within-family response effects tell a different story (Fig.~\ref{fig:endpoints}).
On External-220 and its nested Strict-97 subset, seven of the nine fixed
endpoint configurations have descriptive paired intervals below zero when the
responses are added. These include ExtraTrees, the residual MLP, dual branches,
message passing, a MoLFormer neural head, TabM, and MoLFormer with a tree head.
On ARROW-85, the intervals are below zero for ExtraTrees and the two MoLFormer
endpoints. The neural MoLFormer fit changes from 0.465 to 0.273 on ARROW,
1.332 to 1.111 externally, and 1.685 to 1.450 on Strict-97. The residual
MLP's external response gain does not compensate for its higher absolute error.
Ridge plus a neural residual gives the lowest full-model Strict-97 point estimate,
but removing responses lowers its error further, from 1.429 to 1.294. TabPFN
has the lowest ARROW point estimate, yet its response-minus-no-response intervals
include zero on all three original cohorts.

The mechanisms therefore illuminate different trade-offs rather than a single
winner: separate input branches and the shared-parameter TabM ensemble improve
the size-holdout estimate; message passing makes molecular size available to its
readout without imposing additivity; and the MoLFormer--ExtraTrees pair changes
the molecular representation while retaining a bounded endpoint. A
width-adaptive selection variant reaches 1.090 externally, but its difference
from ExtraTrees is unresolved ($-0.062$; 95\% interval, $-0.157$ to $0.027$).
This variant is a training-side selection rule that can choose different
configurations across partitions, not another architecture. Complete variants,
unsuccessful choices and paired intervals appear in Supplementary Tables~13--15
and Data~6.
