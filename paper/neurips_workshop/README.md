# SIMBIOCHEM II / NeurIPS 2026 workshop manuscript

Anonymous workshop adaptation of the SolvAI response-prior study. The main paper uses
the official `neurips_2026.sty` file with the `dblblindworkshop` option. The complete
anonymized supplementary manuscript is compiled as `appendix.pdf` and appended after
the main references; the SIMBIOCHEM checklist follows it.

Build from this directory with:

```bash
make
```

The review PDF is `main.pdf`. The first eight pages contain the complete workshop
argument; references, appendix, and checklist begin afterward.
