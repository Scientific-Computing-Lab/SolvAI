# Data availability

The canonical 85-solute analysis table, fold assignments, all molecule-level
held-out predictions and all machine-readable manuscript metrics are included
in the SolvAI repository. Redistributable processed response tables are included
with source attribution. Large source archives are referenced by DOI, version,
checksum, licence and reproduction command in `repro/DATA_PROVENANCE.md`.
CombiSolv-QM source records are not redistributed because the publisher
supplement does not state a standalone data licence; researchers can obtain the
file from its canonical publisher URL after accepting the applicable terms.
