# Nature submission file guide

The repository separates the submission components required by the current
Nature guidance.

| Submission component | Repository file(s) |
|---|---|
| Main manuscript, including Methods and Extended Data legends | `paper/main.tex`, `paper/main.pdf` |
| Main display figures | `paper/figures/main/fig1_concept.*` through `fig4_frontier.*` |
| Extended Data figures | `paper/extended_data/ED_Fig1_*` through `ED_Fig7_*` |
| Extended Data table | `paper/extended_data/ED_Table1.*` |
| Supplementary Information, with no figures | `paper/supplementary/supplementary.tex`, `paper/supplementary/supplementary.pdf` |
| Supplementary Data | `paper/supplementary_data/` |
| Combined internal-review PDF (not an SI upload) | `paper/review_combined.pdf` |

Journal-portal metadata requiring author confirmation are isolated in
`submission/AUTHOR_TODOS.md`.
