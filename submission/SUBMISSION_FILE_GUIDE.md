# Nature Communications submission file guide

The repository separates the submission components required by the current
Nature Communications guidance.

| Submission component | Repository file(s) |
|---|---|
| Main manuscript, including Methods | `paper/main.tex`, `paper/main.pdf` |
| Main display figures | `paper/figures/main/fig1_concept.*` through `fig4_frontier.*` |
| Supplementary Information, including tables, five figures and their legends | `paper/supplementary/supplementary.tex`, `paper/supplementary/supplementary.pdf` |
| Supplementary figure source files | `paper/supplementary/figures/Supp_Fig1_*` through `Supp_Fig5_*` |
| Supplementary Data 1 | Complete experiment ledger in `paper/supplementary_data/` |
| Supplementary Data 2 | Molecule-level confirmatory predictions in `paper/supplementary_data/` |
| Supplementary Data 3 | Split and chemical-separation assignments in `paper/supplementary_data/` |
| Supplementary Data 4 | Response-prior and source manifests in `paper/supplementary_data/` |
| Combined internal-review PDF (`main.pdf` followed by the complete SI PDF; not a separate upload) | `paper/review_combined.pdf` |

Journal-portal metadata requiring author confirmation are isolated in
`submission/AUTHOR_TODOS.md`.
