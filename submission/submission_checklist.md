# Submission checklist

- [x] Title and abstract are within the intended Nature Article scope.
- [x] Main and Supplementary PDFs compile from source.
- [x] Every result is regenerated from frozen machine-readable outputs.
- [x] Strict identity audit reports zero retained benchmark overlap.
- [x] SMILES-only inference and artifact hashes are tested.
- [x] Repeated, nested, family and scaffold validation are reported.
- [x] Data and code availability statements are drafted.
- [x] Figures have vector PDF/SVG versions and inspected PNG previews.
- [x] The release tree and Git history pass credential scans.
- [ ] Resolve the human declarations in `AUTHOR_TODOS.md`.
- [ ] Confirm journal-specific file naming and upload fields at submission time.
- [ ] Confirm whether Nature requests a presubmission enquiry for this article type.
