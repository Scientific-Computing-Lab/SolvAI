# Figure source

All quantitative main and Supplementary figures are generated by
[`scripts/make_figures.py`](../../scripts/make_figures.py) from
`results/paper_metrics.json` and the frozen prediction/ablation tables. Figure 1 is
maintained as a native Penpot design in [`../penpot/`](../penpot/); its deterministic
chemistry assets originated in this directory. The former SVGWrite compositions are
retained as provenance and as a reproducible precursor, but no longer overwrite the
art-directed Penpot master.

Run:

```bash
make figures
```

The command installs the frozen Penpot Figure 1 exports, then regenerates Figures
2--4 and five Supplementary Figures from machine-readable results. The discontinued
selective-PIMD plot is retained only under `figures/diagnostics/`. Each publication figure is emitted as
vector PDF, editable SVG and a high-resolution PNG. Matplotlib uses a fixed SVG salt
and fixed PDF metadata so regeneration is deterministic.
