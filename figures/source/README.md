# Figure source

All main and Extended Data figures are generated by
[`scripts/make_figures.py`](../../scripts/make_figures.py) from
`results/paper_metrics.json` and the frozen prediction/ablation tables.

Run:

```bash
make figures
```

Each figure is emitted as vector PDF, editable SVG and 300-dpi PNG. Matplotlib
uses a fixed SVG salt and fixed PDF metadata so regeneration is deterministic.
