\section{Sequential replay implementation}

The replay library stores a rectangular window-by-chunk-by-observation tensor but
exposes a policy only to a frozen state containing lambda, revealed chunk counts,
revealed means, revealed SEMs, cumulative cost and step number. A policy cannot access
the raw chunk tensor or future reference. Tests verify deterministic equal-time and
random replay, recovery of a visibly high-variance synthetic window by max-SEM and
rejection of an ineligible future action. The inherited one-stream library is used for
implementation tests only.

\section{Power and reference reliability}

The minimum-useful effects were -0.341905 and -0.222900 kcal mol$^{-1}$ at five and
seven windows. The reference threshold was 0.111450 kcal mol$^{-1}$. Fifty thousand
Monte Carlo cohorts were generated for each predeclared molecule count and duration.

The reference calculation assumes inverse-square-root noise decay and is therefore
optimistic if slow relaxation or initialization bias persists. The effect calculation
uses v1 policy heterogeneity because no independent v3 policy effect exists. These
limitations make the design a lower-bound planning diagnostic, not a launch proposal.

\section{Negative-result disposition}

No policy model was selected and no prospective cohort was qualified. No new
trajectory, experimental-endpoint analysis, PIMD4/PIMD8 calculation or Tier-B test was
opened. The v3 result is a causal stop: the frozen response coordinates failed to add
sampling-difficulty information, and the minimum powered independent design was not
compatible with the local exploratory envelope.
